# NxfireDB — Website

Landing page resmi [NxfireDB](https://github.com/iyanrsaleh/nxfiredb) — lapisan
lokal di depan Firebase Realtime Database.

NxfireDB: aplikasi Anda mengirim JSON ke `localhost` (127.0.0.1:9026),
NxfireDB yang meneruskannya ke Firebase — plus cache, antrian offline, dan
realtime WebSocket lokal. SDK: Python, JavaScript, C#, Go, PHP.

## Struktur

```
index.html   halaman utama (ID/EN)
index.js     i18n + interaksi
style.css    tema gelap aksen api
logo.png     logo NxfireDB
```
